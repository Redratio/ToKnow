# ToKnow P0 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 2–3 天内交付一个可日常使用的本地学习闭环：完成 onboarding、生成目标树、每天生成规则版主线、完成任务并更新掌握度、每日打卡、查看知识树、**用真正的月历查看与调整任务**、导出备份。

**Architecture:** Electron 主进程承载 SQLite 与业务服务，preload 暴露类型化 IPC，React 渲染层只做展示与交互。所有业务逻辑（规划、掌握度、日期边界）放在 `src/shared` 的纯函数中，便于 Vitest 直接测试；数据库通过 Repository 封装，为后续同步预留 `sync_outbox`。P0 不接 AI、不采集、不做做题工作台。

**Tech Stack:** Electron 44 + electron-vite 6 + React 19 + TypeScript 5.9 + better-sqlite3 13 + Vitest 5 + plain CSS。

## Global Constraints

- **Node.js ≥ 22.12.0**。开发机已验证 v24.20.0；Electron 44、Vite 8、Vitest 5 都要求 22.12+。
- 包管理器：npm 10.8+。
- 平台：Windows 11（代码保持跨平台，不写 Windows 专属路径）。
- 数据库文件位于 `app.getPath('userData')/toknow.db`（测试用 `:memory:`）。
- 时间一律存 Unix 毫秒；日期一律存 `YYYY-MM-DD` 字符串。
- 自然日边界为凌晨 04:00（`getStudyDate`）。
- **可同步实体表**（`study_profile`、`subject`、`module`、`knowledge_node`、`task`、`daily_log`）带 `id`、`created_at`、`updated_at`、`deleted_at`、`device_id`；关联表（`node_prerequisite`、`task_node`）用复合主键；状态表（`user_node_state`）用 `profile_id + node_id`；`evidence`、`setting`、`sync_outbox` 按用途保留最小字段。
- 不引入 UI 组件库、状态管理库、ORM；P0 用 React 内置状态与手写 SQL。
- 不提交任何密钥；P0 无网络请求。
- 数据分层遵循设计文档 3.4 / 6.9：P0 落地 `src/shared/privacy.ts`；规划器不得 import 原始行为事件或日记/反思仓库，只能读聚合或知识层。
- 每个 Task 结束必须 `npm test` 全绿并提交一次。
- **每个 Task 提交前，在 `docs/DEVLOG.md` 追加一条简短记录**：做了什么、`npm test` 结果、下一步。这是上下文交接的主要依据。各 Task 的 **Files** 列表是最小代码文件集；`docs/DEVLOG.md` 始终包含在该 Task 的提交范围内。

- [ ] **Step 3: 写 `src/shared/date.ts`**

```ts
export function getStudyDate(now: Date, boundaryHour = 4): string {
  const d = new Date(now.getTime());
  if (d.getHours() < boundaryHour) {
    d.setDate(d.getDate() - 1);
  }
  const y = d.getFullYear();
  const m = String(d.getMonth() + 1).padStart(2, '0');
  const day = String(d.getDate()).padStart(2, '0');
  return `${y}-${m}-${day}`;
}

export function daysBetween(fromDate: string, toDate: string): number {
  const from = Date.parse(`${fromDate}T00:00:00`);
  const to = Date.parse(`${toDate}T00:00:00`);
  return Math.max(0, Math.round((to - from) / 86_400_000));
}
```

const MIGRATIONS: { version: number; sql: string }[] = [{ version: 1, sql: INIT_SQL }];

export function migrate(db: Database.Database): void {
  const current = db.pragma('user_version', { simple: true }) as number;
  for (const migration of MIGRATIONS) {
    if (migration.version <= current) continue;
    db.exec('BEGIN');
    try {
      db.exec(migration.sql);
      db.pragma(`user_version = ${migration.version}`);
      db.exec('COMMIT');
    } catch (error) {
      db.exec('ROLLBACK');
      throw error;
    }
  }
}

export type DataDomain =
  | 'knowledge'
  | 'behavior'
  | 'reflection'
  | 'derived_profile';

export type DataPurpose = 'planning' | 'display' | 'ai' | 'export';

export type AccessLevel = 'none' | 'aggregate' | 'redacted' | 'confirmed' | 'full';

const POLICY: Record<DataDomain, Record<DataPurpose, AccessLevel>> = {
  knowledge: {
    planning: 'full',
    display: 'full',
    ai: 'full',
    export: 'full'
  },
  behavior: {
    planning: 'aggregate',
    display: 'full',
    ai: 'aggregate',
    export: 'redacted'
  },
  reflection: {
    planning: 'none',
    display: 'full',
    ai: 'none',
    export: 'none'
  },
  derived_profile: {
    planning: 'confirmed',
    display: 'full',
    ai: 'confirmed',
    export: 'full'
  }
};

export function accessLevel(
  domain: DataDomain,
  purpose: DataPurpose
): AccessLevel {
  return POLICY[domain][purpose] ?? 'none';
}

export function canRead(domain: DataDomain, purpose: DataPurpose): boolean {
  return accessLevel(domain, purpose) !== 'none';
}

import type Database from 'better-sqlite3';
import { randomUUID } from 'node:crypto';
import type { OnboardingInput, Profile } from '../../shared/types';
import { getStudyDate } from '../../shared/date';
import { insertProfile } from '../repositories/profileRepo';
import { seedTargetTree } from '../seed/targetTree';

export function validateOnboarding(
  input: OnboardingInput,
  today = getStudyDate(new Date())
): string[] {
  const errors: string[] = [];
  if (!input.name.trim()) errors.push('name_required');
  if (!/^\d{4}-\d{2}-\d{2}$/.test(input.examDate)) {
    errors.push('exam_date_invalid');
  } else if (input.examDate <= today) {
    errors.push('exam_date_past');
  }
  if (input.dailyCapacityMin < 60 || input.dailyCapacityMin > 900) {
    errors.push('capacity_range');
  }
  for (const value of Object.values(input.selfRatings)) {
    if (!Number.isFinite(value) || value < 0 || value > 5) {
      errors.push('rating_range');
      break;
    }
  }
  return errors;
}

export function submitOnboarding(
  db: Database.Database,
  input: OnboardingInput,
  today = getStudyDate(new Date())
): Profile {
  const errors = validateOnboarding(input, today);
  if (errors.length > 0) {
    throw new Error(`INVALID_ONBOARDING:${errors.join(',')}`);
  }

  const profile: Profile = {
    id: randomUUID(),
    name: input.name.trim(),
    examDate: input.examDate,
    dailyCapacityMin: input.dailyCapacityMin,
    timezone: 'Asia/Shanghai',
    active: true
  };

  const tx = db.transaction(() => {
    insertProfile(db, profile);
    seedTargetTree(db, profile.id);

    const updateState = db.prepare(
      `UPDATE user_node_state
       SET self_rating = ?, mastery = ?, confidence = 0.5, updated_by = 'self', updated_at = ?
       WHERE profile_id = ?
         AND node_id IN (
           SELECT n.id FROM knowledge_node n
           JOIN module m ON m.id = n.module_id
           JOIN subject s ON s.id = m.subject_id
           WHERE s.profile_id = ? AND s.code = ?
         )`
    );

    for (const [code, rating] of Object.entries(input.selfRatings)) {
      updateState.run(rating, rating, Date.now(), profile.id, profile.id, code);
    }
  });

  tx();
  return profile;
}

```ts
import { daysBetween } from './date';

export interface PlannerNode {
  nodeId: string;
  moduleId: string;
  subjectId: string;
  title: string;
  examWeight: number;
  mastery: number;
  targetMastery: number;
  lastStudiedAt: number | null;
}

export interface PlannerInput {
  today: string;
  examDate: string;
  dailyCapacityMin: number;
  nowMs: number;
  nodes: PlannerNode[];
  maxTasks?: number;
}

export interface RankedNode extends PlannerNode {
  score: number;
}

export interface DailySelection {
  mainline: RankedNode;
  supporting: RankedNode[];
  plannedMin: number;
}

export function urgency(daysLeft: number): number {
  return 1 + Math.max(0, (90 - daysLeft) / 90);
}

export function forgetting(lastStudiedAt: number | null, nowMs: number): number {
  if (lastStudiedAt === null) return 1;
  const days = Math.max(0, (nowMs - lastStudiedAt) / 86_400_000);
  return 1 + Math.min(1, days / 14);
}

export function priority(node: PlannerNode, daysLeft: number, nowMs: number): number {
  const weakness = Math.max(0, 1 - node.mastery / 5);
  const targetGap = Math.max(0, (node.targetMastery - node.mastery) / 5);
  return (
    node.examWeight *
    (weakness + targetGap) *
    urgency(daysLeft) *
    forgetting(node.lastStudiedAt, nowMs)
  );
}

export function selectDailyPlan(input: PlannerInput): DailySelection | null {
  const daysLeft = daysBetween(input.today, input.examDate);
  const ranked: RankedNode[] = input.nodes
    .filter((node) => node.mastery < node.targetMastery)
    .map((node) => ({
      ...node,
      score: priority(node, daysLeft, input.nowMs)
    }))
    .sort((a, b) => b.score - a.score);

  if (ranked.length === 0) return null;

  // 1 条主线 + 最多 2 条辅助是硬契约，maxTasks 只能在此区间内收窄
  const maxTasks = Math.min(3, Math.max(1, input.maxTasks ?? 3));
  const picked = ranked.slice(0, maxTasks);
  const plannedMin = Math.max(
    10,
    Math.min(60, Math.floor(input.dailyCapacityMin / picked.length))
  );

  return {
    mainline: picked[0],
    supporting: picked.slice(1),
    plannedMin
  };
}
```

```ts
export type EvidenceKind =
  | 'real_exam'
  | 'practice'
  | 'self_test'
  | 'task_completion'
  | 'self_rating';

export const EVIDENCE_ALPHA: Record<EvidenceKind, number> = {
  real_exam: 0.35,
  practice: 0.25,
  self_test: 0.2,
  task_completion: 0.1,
  self_rating: 0.15
};

/**
 * 掌握度更新（设计文档 8.2）。
 * current 与返回值是 0–5；performance 是归一化到 0–1 的表现分。
 * 一次证据最多把掌握度推动 alpha 点，所以任务完成只是弱证据。
 */
export function updateMastery(
  current: number,
  performance: number,
  alpha: number
): number {
  const expected = current / 5;
  const next = current + alpha * (performance - expected);
  const clamped = Math.min(5, Math.max(0, next));
  return Math.round(clamped * 100) / 100;
}
```

export function listPlannerNodes(
  db: Database.Database,
  profileId: string
): PlannerNode[] {
  const rows = db
    .prepare(
      `SELECT n.id AS node_id, n.module_id, m.subject_id, n.title,
              n.exam_weight, n.target_mastery,
              COALESCE(uns.mastery, 0) AS mastery,
              uns.last_studied_at
       FROM knowledge_node n
       JOIN module m ON m.id = n.module_id
       JOIN subject s ON s.id = m.subject_id
       LEFT JOIN user_node_state uns
         ON uns.node_id = n.id AND uns.profile_id = s.profile_id
       WHERE s.profile_id = ? AND n.deleted_at IS NULL`
    )
    .all(profileId) as {
    node_id: string;
    module_id: string;
    subject_id: string;
    title: string;
    exam_weight: number;
    target_mastery: number;
    mastery: number;
    last_studied_at: number | null;
  }[];

  return rows.map((row) => ({
    nodeId: row.node_id,
    moduleId: row.module_id,
    subjectId: row.subject_id,
    title: row.title,
    examWeight: row.exam_weight,
    mastery: row.mastery,
    targetMastery: row.target_mastery,
    lastStudiedAt: row.last_studied_at
  }));
}

export function applyEvidence(
  db: Database.Database,
  profileId: string,
  nodeId: string,
  taskId: string | null,
  kind: EvidenceKind,
  performance: number,
  nowMs: number
): number {
  const state = db
    .prepare(
      'SELECT mastery, confidence FROM user_node_state WHERE profile_id = ? AND node_id = ?'
    )
    .get(profileId, nodeId) as { mastery: number; confidence: number } | undefined;

  const current = state?.mastery ?? 0;
  const expected = current / 5;
  const weight = EVIDENCE_ALPHA[kind];
  const next = updateMastery(current, performance, weight);
  const confidence = Math.min(1, (state?.confidence ?? 0) + 0.05);

  if (state) {
    db.prepare(
      `UPDATE user_node_state
       SET mastery = ?, confidence = ?, last_studied_at = ?,
           review_count = review_count + 1, updated_by = 'evidence', updated_at = ?
       WHERE profile_id = ? AND node_id = ?`
    ).run(next, confidence, nowMs, nowMs, profileId, nodeId);
  } else {
    db.prepare(
      `INSERT INTO user_node_state
        (profile_id, node_id, self_rating, mastery, confidence,
         last_studied_at, next_review_at, review_count, updated_by, updated_at)
       VALUES (?, ?, 0, ?, ?, ?, NULL, 1, 'evidence', ?)`
    ).run(profileId, nodeId, next, confidence, nowMs, nowMs);
  }

  db.prepare(
    `INSERT INTO evidence
      (id, node_id, task_id, kind, performance, expected, weight, meta_json, created_at)
     VALUES (?, ?, ?, ?, ?, ?, ?, NULL, ?)`
  ).run(randomUUID(), nodeId, taskId, kind, performance, expected, weight, nowMs);

  return next;
}

import type Database from 'better-sqlite3';
import { randomUUID } from 'node:crypto';
import { selectDailyPlan } from '../../shared/planner';
import type {
  CompleteTaskInput,
  CompleteTaskResult,
  DailyPlan,
  Task
} from '../../shared/types';
import { getActiveProfile } from '../repositories/profileRepo';
import {
  getTaskById,
  insertTask,
  linkTaskNode,
  listNodeIdsForTask,
  listTasksForDate,
  markTaskDone
} from '../repositories/taskRepo';
import { applyEvidence, listPlannerNodes } from '../repositories/treeRepo';

function buildPlan(tasks: Task[], date: string): DailyPlan {
  const mainline = tasks.find((t) => t.isMainline) ?? null;
  const supporting = tasks.filter((t) => !t.isMainline);
  return {
    date,
    mainline,
    supporting,
    totalPlannedMin: tasks.reduce((sum, t) => sum + t.plannedMin, 0)
  };
}

export function generateDailyPlan(
  db: Database.Database,
  profileId: string,
  date: string,
  nowMs: number
): DailyPlan {
  const existing = listTasksForDate(db, profileId, date);
  if (existing.length > 0) return buildPlan(existing, date);

  const profile = getActiveProfile(db);
  if (!profile) throw new Error('NO_PROFILE');

  const selection = selectDailyPlan({
    today: date,
    examDate: profile.examDate,
    dailyCapacityMin: profile.dailyCapacityMin,
    nowMs,
    nodes: listPlannerNodes(db, profileId)
  });

  if (!selection) return { date, mainline: null, supporting: [], totalPlannedMin: 0 };

  const ranked = [selection.mainline, ...selection.supporting];
  const tx = db.transaction(() => {
    ranked.forEach((node, index) => {
      const task: Task = {
        id: randomUUID(),
        profileId,
        title: `${index === 0 ? '主线' : '配套'} · ${node.title}`,
        type: index === 0 ? 'study' : 'review',
        plannedMin: selection.plannedMin,
        actualMin: null,
        scheduledDate: date,
        status: 'todo',
        priorityScore: node.score,
        isMainline: index === 0,
        source: 'plan',
        locked: false,
        notes: null,
        createdAt: nowMs,
        updatedAt: nowMs
      };
      insertTask(db, task);
      linkTaskNode(db, task.id, node.nodeId);
    });
  });
  tx();

  return buildPlan(listTasksForDate(db, profileId, date), date);
}

export function completeTask(
  db: Database.Database,
  profileId: string,
  input: CompleteTaskInput,
  nowMs: number
): CompleteTaskResult {
  const task = getTaskById(db, input.taskId);
  if (!task) throw new Error('TASK_NOT_FOUND');
  if (task.status === 'done') return { task, mastery: {} };

  const performance = Math.min(5, Math.max(0, input.performance));
  const actualMin = Math.max(0, Math.round(input.actualMin));
  const mastery: Record<string, number> = {};

  const tx = db.transaction(() => {
    markTaskDone(db, task.id, actualMin, nowMs);
    for (const nodeId of listNodeIdsForTask(db, task.id)) {
      mastery[nodeId] = applyEvidence(
        db,
        profileId,
        nodeId,
        task.id,
        'task_completion',
        performance / 5,
        nowMs
      );
    }
  });
  tx();

  const updated = getTaskById(db, task.id) ?? task;
  return { task: updated, mastery };
}

import type Database from 'better-sqlite3';
import type {
  KnowledgeNode,
  TreeModule,
  TreeNode,
  TreeSubject
} from '../../shared/types';
import { mapNode, mapState } from '../db/rows';
import {
  listModules,
  listNodes,
  listStates,
  listSubjects
} from '../repositories/treeRepo';

export function getTree(
  db: Database.Database,
  profileId: string
): TreeSubject[] {
  const subjects = listSubjects(db, profileId);
  const modules = listModules(db, profileId);
  const nodeRows = listNodes(db, profileId);
  const states = new Map(
    listStates(db, profileId).map((row) => [row.node_id, mapState(row)])
  );

  const nodeMap = new Map<string, TreeNode>();
  for (const row of nodeRows) {
    const node: KnowledgeNode = mapNode(row);
    const state = states.get(node.id) ?? {
      nodeId: node.id,
      selfRating: 0,
      mastery: 0,
      confidence: 0,
      lastStudiedAt: null,
      nextReviewAt: null,
      reviewCount: 0,
      updatedBy: 'self' as const,
      updatedAt: 0
    };
    nodeMap.set(node.id, { ...node, state, children: [] });
  }

  for (const node of nodeMap.values()) {
    if (node.parentId && nodeMap.has(node.parentId)) {
      nodeMap.get(node.parentId)!.children.push(node);
    }
  }

  const moduleMap = new Map<string, TreeModule>();
  for (const module of modules) {
    moduleMap.set(module.id, { ...module, nodes: [] });
  }
  for (const node of nodeMap.values()) {
    if (!node.parentId) moduleMap.get(node.moduleId)?.nodes.push(node);
  }

  const subjectMap = new Map<string, TreeSubject>();
  for (const subject of subjects) {
    subjectMap.set(subject.id, { ...subject, modules: [] });
  }
  for (const module of moduleMap.values()) {
    subjectMap.get(module.subjectId)?.modules.push(module);
  }

  const sortNodes = (nodes: TreeNode[]): void => {
    nodes.sort((a, b) => a.orderIndex - b.orderIndex);
    nodes.forEach((n) => sortNodes(n.children));
  };
  for (const subject of subjectMap.values()) {
    subject.modules.sort((a, b) => a.orderIndex - b.orderIndex);
    subject.modules.forEach((m) => sortNodes(m.nodes));
  }

  return [...subjectMap.values()];
}

import type Database from 'better-sqlite3';
import { randomUUID } from 'node:crypto';
import type { DailyLog, DailyLogInput } from '../../shared/types';
import { mapDailyLog, type DailyLogRow } from '../db/rows';

function validate(input: DailyLogInput): void {
  const inRange = (v: number | null, min: number, max: number): boolean =>
    v === null || (Number.isFinite(v) && v >= min && v <= max);
  if (
    !inRange(input.sleepHours, 0, 24) ||
    !inRange(input.energy, 1, 5) ||
    !inRange(input.mood, 1, 5) ||
    !inRange(input.focusSelf, 1, 5)
  ) {
    throw new Error('INVALID_DAILY_LOG');
  }
}

export function upsertDailyLog(
  db: Database.Database,
  profileId: string,
  input: DailyLogInput,
  nowMs: number
): DailyLog {
  validate(input);

  const existing = getDailyLog(db, profileId, input.date);
  const id = existing?.id ?? randomUUID();

  db.prepare(
    `INSERT INTO daily_log
      (id, profile_id, date, sleep_hours, energy, mood, focus_self, note,
       checkin_at, created_at, updated_at, device_id)
     VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
     ON CONFLICT(profile_id, date) DO UPDATE SET
       sleep_hours = excluded.sleep_hours,
       energy = excluded.energy,
       mood = excluded.mood,
       focus_self = excluded.focus_self,
       note = excluded.note,
       checkin_at = excluded.checkin_at,
       updated_at = excluded.updated_at`
  ).run(
    id,
    profileId,
    input.date,
    input.sleepHours,
    input.energy,
    input.mood,
    input.focusSelf,
    input.note ?? null,
    nowMs,
    nowMs,
    nowMs,
    'local'
  );

  return getDailyLog(db, profileId, input.date)!;
}

export function getDailyLog(
  db: Database.Database,
  profileId: string,
  date: string
): DailyLog | null {
  const row = db
    .prepare(
      'SELECT * FROM daily_log WHERE profile_id = ? AND date = ? AND deleted_at IS NULL'
    )
    .get(profileId, date) as DailyLogRow | undefined;
  return row ? mapDailyLog(row) : null;
}

import type Database from 'better-sqlite3';
import { mkdirSync, writeFileSync } from 'node:fs';
import path from 'node:path';
import type { BackupResult } from '../../shared/types';
import {
  mapDailyLog,
  mapNode,
  mapProfile,
  mapState,
  mapTask,
  type DailyLogRow,
  type NodeRow,
  type ProfileRow,
  type StateRow,
  type TaskRow
} from '../db/rows';
import { listSubjects } from '../repositories/treeRepo';

function stamp(now: Date): string {
  const pad = (n: number): string => String(n).padStart(2, '0');
  return [
    now.getFullYear(),
    pad(now.getMonth() + 1),
    pad(now.getDate()),
    '-',
    pad(now.getHours()),
    pad(now.getMinutes()),
    pad(now.getSeconds())
  ].join('');
}

export async function exportBackup(
  db: Database.Database,
  destDir: string,
  now = new Date()
): Promise<BackupResult> {
  mkdirSync(destDir, { recursive: true });
  const base = `toknow-backup-${stamp(now)}`;
  const dbPath = path.join(destDir, `${base}.db`);
  const jsonPath = path.join(destDir, `${base}.json`);

  await db.backup(dbPath);

  const profileRow = db
    .prepare('SELECT * FROM study_profile ORDER BY created_at DESC LIMIT 1')
    .get() as ProfileRow | undefined;

  const payload = {
    exportedAt: now.toISOString(),
    profile: profileRow ? mapProfile(profileRow) : null,
    subjects: profileRow ? listSubjects(db, profileRow.id) : [],
    nodes: (
      db.prepare('SELECT * FROM knowledge_node WHERE deleted_at IS NULL').all() as NodeRow[]
    ).map(mapNode),
    states: (
      db.prepare('SELECT * FROM user_node_state').all() as StateRow[]
    ).map(mapState),
    tasks: (
      db.prepare('SELECT * FROM task WHERE deleted_at IS NULL').all() as TaskRow[]
    ).map(mapTask),
    // 反思层原文不进入默认导出：保留数值字段，note 置空。
    dailyLogs: (
      db.prepare('SELECT * FROM daily_log').all() as DailyLogRow[]
    ).map((row) => ({ ...mapDailyLog(row), note: null }))
  };

  writeFileSync(jsonPath, JSON.stringify(payload, null, 2), 'utf8');
  return { dbPath, jsonPath };
}

import type Database from 'better-sqlite3';
import type { IpcMain } from 'electron';

import { IPC, type AppSettings, type Bootstrap } from '../shared/ipc';
import type {
  BackupResult,

  OnboardingInput,

  TodayView,
  TreeSubject

import { exportBackup as exportBackupService } from './services/backupService';
import { completeTask as completeTaskService } from './services/planService';
import { getTodayView } from './services/todayService';
import { submitOnboarding as submitOnboardingService } from './services/onboardingService';
import { getTree as getTreeService } from './services/treeService';

export interface HandlerContext {
  db: Database.Database;
  dbPath: string;
  backupDir: string;
  version: string;
}

export function createHandlers(ctx: HandlerContext) {
  const requireProfile = (): Profile => {
    const profile = getActiveProfile(ctx.db);
    if (!profile) throw new Error('NO_PROFILE');
    return profile;
  };

  return {
    bootstrap: (): Bootstrap => ({
      profile: getActiveProfile(ctx.db),
      today: getStudyDate(new Date())
    }),
    submitOnboarding: (input: OnboardingInput): Profile =>
      submitOnboardingService(ctx.db, input),
    getToday: (): TodayView =>
      getTodayView(ctx.db, requireProfile().id, getStudyDate(new Date()), Date.now()),
    completeTask: (input: CompleteTaskInput): CompleteTaskResult =>
      completeTaskService(ctx.db, requireProfile().id, input, Date.now()),
    checkIn: (input: DailyLogInput): DailyLog =>
      upsertDailyLog(ctx.db, requireProfile().id, input, Date.now()),
    getTree: (): TreeSubject[] => getTreeService(ctx.db, requireProfile().id),
    exportBackup: (): Promise<BackupResult> =>
      exportBackupService(ctx.db, ctx.backupDir),
    getSettings: (): AppSettings => ({
      dbPath: ctx.dbPath,
      backupDir: ctx.backupDir,
      version: ctx.version
    })
  };
}

export type AppHandlers = ReturnType<typeof createHandlers>;

export function registerIpc(ipcMain: IpcMain, handlers: AppHandlers): void {
  ipcMain.handle(IPC.bootstrap, () => handlers.bootstrap());
  ipcMain.handle(IPC.onboarding, (_event, input: OnboardingInput) =>
    handlers.submitOnboarding(input)
  );
  ipcMain.handle(IPC.today, () => handlers.getToday());
  ipcMain.handle(IPC.completeTask, (_event, input: CompleteTaskInput) =>
    handlers.completeTask(input)
  );
  ipcMain.handle(IPC.checkIn, (_event, input: DailyLogInput) =>
    handlers.checkIn(input)
  );
  ipcMain.handle(IPC.tree, () => handlers.getTree());
  ipcMain.handle(IPC.exportBackup, () => handlers.exportBackup());
  ipcMain.handle(IPC.settings, () => handlers.getSettings());
}

const DATE_RE = /^\d{4}-\d{2}-\d{2}$/;

function pad(value: number): string {
  return String(value).padStart(2, '0');
}

function assertDate(date: string): void {
  if (!DATE_RE.test(date)) throw new Error('INVALID_DATE');
  const parsed = new Date(`${date}T00:00:00`);
  if (
    Number.isNaN(parsed.getTime()) ||
    parsed.getFullYear() !== Number(date.slice(0, 4)) ||
    parsed.getMonth() + 1 !== Number(date.slice(5, 7)) ||
    parsed.getDate() !== Number(date.slice(8, 10))
  ) {
    throw new Error('INVALID_DATE');
  }
}

export function monthBounds(
  year: number,
  month: number
): { start: string; end: string } {
  if (!Number.isInteger(year) || year < 2000 || year > 2100) {
    throw new Error('INVALID_MONTH');
  }
  if (!Number.isInteger(month) || month < 1 || month > 12) {
    throw new Error('INVALID_MONTH');
  }
  const daysInMonth = new Date(year, month, 0).getDate();
  return {
    start: `${year}-${pad(month)}-01`,
    end: `${year}-${pad(month)}-${pad(daysInMonth)}`
  };
}

export function getMonthView(
  db: Database.Database,
  profileId: string,
  year: number,
  month: number
): CalendarMonthView {
  const { start, end } = monthBounds(year, month);
  const tasks = listTasksForMonth(db, profileId, start, end);
  const logs = listDailyLogsBetween(db, profileId, start, end);
  const checkinDates = new Set(logs.map((log) => log.date));

  const byDate = new Map<string, Task[]>();
  for (const task of tasks) {
    const list = byDate.get(task.scheduledDate) ?? [];
    list.push(task);
    byDate.set(task.scheduledDate, list);
  }

  const daysInMonth = new Date(year, month, 0).getDate();
  const days: CalendarDay[] = [];
  for (let day = 1; day <= daysInMonth; day += 1) {
    const date = `${year}-${pad(month)}-${pad(day)}`;
    const dayTasks = byDate.get(date) ?? [];
    days.push({
      date,
      taskCount: dayTasks.length,
      doneCount: dayTasks.filter((task) => task.status === 'done').length,
      plannedMin: dayTasks.reduce((sum, task) => sum + task.plannedMin, 0),
      hasCheckIn: checkinDates.has(date)
    });
  }

  return { year, month, days, tasks };
}

export function getDayView(
  db: Database.Database,
  profileId: string,
  date: string
): CalendarDayView {
  assertDate(date);
  return {
    date,
    tasks: listTasksForDate(db, profileId, date),
    dailyLog: getDailyLog(db, profileId, date)
  };
}

export function createManualTask(
  db: Database.Database,
  profileId: string,
  input: CreateTaskInput,
  nowMs: number
): Task {
  const title = input.title.trim();
  if (title.length < 1 || title.length > 120) {
    throw new Error('INVALID_TASK_TITLE');
  }
  assertDate(input.date);
  if (
    !Number.isInteger(input.plannedMin) ||
    input.plannedMin < 5 ||
    input.plannedMin > 600
  ) {
    throw new Error('INVALID_TASK_MINUTES');
  }

  const task: Task = {
    id: randomUUID(),
    profileId,
    title,
    type: 'study',
    plannedMin: input.plannedMin,
    actualMin: null,
    scheduledDate: input.date,
    status: 'todo',
    priorityScore: 0,
    isMainline: false,
    source: 'manual',
    locked: false,
    notes: null,
    createdAt: nowMs,
    updatedAt: nowMs
  };

  const tx = db.transaction(() => {
    insertTask(db, task);
    if (input.nodeId) linkTaskNode(db, task.id, input.nodeId);
  });
  tx();
  return task;
}

export function rescheduleTask(
  db: Database.Database,
  profileId: string,
  input: MoveTaskInput,
  nowMs: number
): Task {
  assertDate(input.date);
  const task = getTaskById(db, input.taskId);
  if (!task || task.profileId !== profileId) {
    throw new Error('TASK_NOT_FOUND');
  }
  updateTaskDate(db, task.id, input.date, nowMs);
  return getTaskById(db, task.id)!;
}

import {
  useCallback,
  useEffect,
  useRef,
  useState,
  type FormEvent
} from 'react';
import { Link } from 'react-router-dom';
import { getStudyDate } from '../../../shared/date';
import type {
  CalendarDayView,
  CalendarMonthView,
  Task
} from '../../../shared/types';
import { api } from '../api';

const WEEKDAYS = ['一', '二', '三', '四', '五', '六', '日'];

function pad(value: number): string {
  return String(value).padStart(2, '0');
}

export default function CalendarPage() {
  const today = getStudyDate(new Date());
  const [cursor, setCursor] = useState(() => {
    const [year, month] = today.split('-').map(Number);
    return { year, month };
  });
  const [selectedDate, setSelectedDate] = useState(today);
  const [month, setMonth] = useState<CalendarMonthView | null>(null);
  const [day, setDay] = useState<CalendarDayView | null>(null);
  const [title, setTitle] = useState('');
  const [minutes, setMinutes] = useState(45);
  const [message, setMessage] = useState<string | null>(null);
  const [error, setError] = useState<string | null>(null);
  const titleRef = useRef<HTMLInputElement>(null);

  const refresh = useCallback(async () => {
    const [monthView, dayView] = await Promise.all([
      api.getCalendarMonth(cursor.year, cursor.month),
      api.getCalendarDay(selectedDate)
    ]);
    setMonth(monthView);
    setDay(dayView);
  }, [cursor.year, cursor.month, selectedDate]);

  useEffect(() => {
    refresh().catch((e: unknown) => setError(String(e)));
  }, [refresh]);

  function goMonth(delta: number) {
    const next = new Date(cursor.year, cursor.month - 1 + delta, 1);
    const year = next.getFullYear();
    const monthIndex = next.getMonth() + 1;
    setCursor({ year, month: monthIndex });
    setSelectedDate(`${year}-${pad(monthIndex)}-01`);
  }

  function goToday() {
    const [year, monthIndex] = today.split('-').map(Number);
    setCursor({ year, month: monthIndex });
    setSelectedDate(today);
  }

  async function handleCreate(event: FormEvent) {
    event.preventDefault();
    setMessage(null);
    setError(null);
    try {
      await api.createTask({ title, date: selectedDate, plannedMin: minutes });
      setTitle('');
      await refresh();
      setMessage('已添加到这一天');
    } catch (err) {
      setError(String(err));
    }
  }

  async function handleComplete(task: Task) {
    if (task.status === 'done') return;
    setError(null);
    try {
      await api.completeTask({
        taskId: task.id,
        actualMin: task.plannedMin,
        performance: 3
      });
      await refresh();
    } catch (err) {
      setError(String(err));
    }
  }

  async function handleMove(taskId: string, date: string) {
    setError(null);
    try {
      await api.moveTask({ taskId, date });
      await refresh();
      setMessage('已改期');
    } catch (err) {
      setError(String(err));
    }
  }

  const offset = month
    ? (new Date(month.year, month.month - 1, 1).getDay() + 6) % 7
    : 0;

  return (
    <div className="page calendar-page">
      <div className="page-head calendar-head">
        <div>
          <h1>日历</h1>
          <p className="muted">
            点选一天查看安排；双击日期把光标放到新任务；把任务拖到另一天即可改期。
          </p>
        </div>
        <div className="calendar-nav">
          <button onClick={() => goMonth(-1)} aria-label="上个月">‹</button>
          <strong>{cursor.year} 年 {cursor.month} 月</strong>
          <button onClick={() => goMonth(1)} aria-label="下个月">›</button>
          <button onClick={goToday}>今天</button>
        </div>
      </div>

      {error && <p className="errors">{error}</p>}

      <div className="calendar-layout">
        <section className="calendar-grid" aria-label="月历">
          {WEEKDAYS.map((weekday) => (
            <div key={weekday} className="cal-weekday">{weekday}</div>
          ))}
          {Array.from({ length: offset }, (_, index) => (
            <div key={`blank-${index}`} className="cal-cell blank" />
          ))}
          {month?.days.map((entry) => (
            <button
              key={entry.date}
              type="button"
              className={`cal-cell${entry.date === selectedDate ? ' selected' : ''}${entry.date === today ? ' today' : ''}`}
              onClick={() => setSelectedDate(entry.date)}
              onDoubleClick={() => {
                setSelectedDate(entry.date);
                titleRef.current?.focus();
              }}
              onDragOver={(event) => event.preventDefault()}
              onDrop={(event) => {
                event.preventDefault();
                const taskId = event.dataTransfer.getData('text/task-id');
                if (taskId) void handleMove(taskId, entry.date);
              }}
            >
              <span className="cal-date">{Number(entry.date.slice(8))}</span>
              {entry.hasCheckIn && <span className="cal-dot" title="已打卡" />}
              <span className="cal-count">
                {entry.taskCount > 0 ? `${entry.doneCount}/${entry.taskCount}` : ''}
              </span>
              <span
                className="cal-load"
                style={{ width: `${Math.min(100, entry.plannedMin / 6)}%` }}
              />
            </button>
          ))}
        </section>

        <aside className="calendar-day">
          <div className="calendar-day-head">
            <h2>{selectedDate}</h2>
            <span className="muted">{day?.dailyLog ? '已打卡' : '未打卡'}</span>
          </div>

          {day && day.tasks.length === 0 && (
            <p className="empty">这一天还没有安排。先加一件具体的事。</p>
          )}

          <ul className="cal-task-list">
            {day?.tasks.map((task) => (
              <li
                key={task.id}
                className={`cal-task${task.status === 'done' ? ' done' : ''}`}
                draggable
                onDragStart={(event) =>
                  event.dataTransfer.setData('text/task-id', task.id)

              >
                <input
                  type="checkbox"
                  checked={task.status === 'done'}
                  onChange={() => void handleComplete(task)}
                  aria-label={`完成 ${task.title}`}
                />
                <span className="cal-task-title">{task.title}</span>
                <span className="cal-task-min">{task.plannedMin}′</span>
              </li>
            ))}
          </ul>

          <form className="cal-form" onSubmit={handleCreate}>
            <label>
              新任务
              <input
                ref={titleRef}
                value={title}
                onChange={(event) => setTitle(event.target.value)}
                placeholder="例如：电路第三章错题 1–10"
                maxLength={120}
                required
              />
            </label>
            <label>
              计划分钟
              <input
                type="number"
                min={5}
                max={600}
                value={minutes}
                onChange={(event) => setMinutes(Number(event.target.value))}
              />
            </label>
            <button className="primary" type="submit">加到这一天</button>
          </form>

          {message && <p className="message">{message}</p>}
          <p className="muted">

          </p>
        </aside>
      </div>
    </div>
  );
}

## 计划自检

- **规格覆盖（P0 范围）**：onboarding、目标树、今日主线、任务完成、打卡、结构化日历（新建/改期/完成）、知识树、备份导出均有对应任务；AI/采集/做题工作台明确不在 P0。
- **结构优先**：日历是 7 列月网格 + 日详情，所有核心操作（点选、双击新建、拖拽改期、勾选完成）不依赖 AI；AI 在 P0 完全不参与界面结构。
- **数据分层**：3.4 / 6.9 的访问矩阵在 Task 3 以 `privacy.ts` 落地并有测试；P0 的 `daily_log.note` 属于反思层，只用于界面展示，不进入规划、AI 或默认导出。
- **依赖顺序**：`dailyLogRepo.getDailyLog` 在 Task 8 先落地，Task 9 补写入，避免 Task 8 引用尚不存在的模块。
- **类型一致性**：`PlannerNode` 字段与 `treeRepo.listPlannerNodes` 返回一致；`CompleteTaskInput` 与 `completeTask` 参数一致；`AppApi` 与 preload 方法一一对应。
- **数据边界**：P0 的任务完成只产生弱证据（performance 由用户填写，expected=3，weight=0.4），不把“点完成”等同于“已掌握”。
- **无占位符**：每个代码步骤均给出可执行内容，每个测试均给出断言与预期结果。
